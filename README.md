# 룸톤 Roomtone — Windows 내려받기

매장·카페·호텔에 트는 배경음악 앱의 **윈도(PC)판 배포 저장소**입니다. 소스 코드는 여기에 없고, 설치 파일만 올라옵니다.

- 최신판 내려받기 → [Releases](https://github.com/kimlog0415/RoomTone-releases/releases/latest)
- 제품 소개·구독 → <https://roomtone.logstone.net>
- 문의 → support@logstone.net

안드로이드 태블릿·폰으로 쓰시려면 Google Play에서 「룸톤」을 찾으시면 됩니다.

## 설치

설치 프로그램이 없습니다. 압축을 풀고 바로 실행하시면 됩니다.

1. Releases에서 `Roomtone-x.y.z-win-x64.zip`을 받아 **폴더째 풀어 주세요.** 바탕화면이나 `C:\룸톤`처럼 지우지 않을 자리가 좋습니다. 안에 있는 파일을 따로 꺼내면 실행되지 않습니다.
2. 폴더 안의 **`roomtone_player.exe`** 를 실행하세요. 처음 실행할 때 윈도가 「알 수 없는 발행자」라고 물으면 「추가 정보」 → 「실행」을 눌러 주세요.
3. 자주 쓰시면 그 파일에서 오른쪽 클릭 → 「바로 가기 만들기」로 바탕화면에 두시면 됩니다.
4. 로그인하고, 처음이면 「3일 무료 체험 시작」을 누르세요. 체험이 끝나면 30초 미리듣기로 돌아가고 자동으로 결제되지는 않습니다.
5. 영업시간대로 틀려면 **스케줄** 탭에서 요일·시간을 정해 두세요. 안내방송도 같은 탭에서 시간을 정합니다.

필요한 환경은 64비트 윈도 10 이상과 인터넷 연결입니다.

## 알아 두실 것

- **창의 X를 눌러도 음악은 계속 나옵니다.** 창이 작업표시줄 오른쪽 아래 트레이로 내려갈 뿐입니다. 다시 열려면 트레이의 룸톤 아이콘을 누르세요.
- **완전히 끄려면** 트레이 아이콘에서 오른쪽 클릭 → 「룸톤 종료」를 누르세요.
- 한 PC에서 **두 번 실행되지 않습니다.** 이미 켜져 있으면 그 창이 다시 열립니다.
- **한 계정으로 한 대에서만 재생됩니다.** 다른 기기에서 틀려면 그 기기에서 「여기서 재생」을 누르면 됩니다.
- 새 판이 나오면 앱 위에 **업데이트 띠**가 뜹니다. 그때 다시 받아 폴더를 덮어써 주세요(설정은 남습니다).
- PC에서는 구독을 웹에서 결제합니다(설정 › 구독). 안드로이드 앱은 Google Play 결제입니다.

# Roomtone — Windows download

Background music for shops, cafés, hotels and restaurants. This repository hosts the **Windows build only** — no source code.

- Latest build → [Releases](https://github.com/kimlog0415/RoomTone-releases/releases/latest)
- About and subscription → <https://roomtone.logstone.net>
- Support → support@logstone.net

There is no installer. Unzip the folder, keep it together, and run `roomtone_player.exe`. Closing the window hides it to the tray and the music keeps playing; quit from the tray menu. Requires 64-bit Windows 10 or later and an internet connection.
